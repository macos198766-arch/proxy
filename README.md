# Простой http/https прокси

Прокси сервер выступает посредником между клиентом и сервером. Данный прокси умеет обрабатывать запросы и ответы, http и https соединения.
При подключении клиента(например, браузера) парсится сетевой запрос от него, оттуда берется хост и порт, прокси подключается к нему через открытие нового сокета для каждого клиента в потоке. Для https трафика создается 2 туннеля для пересыки байтов, http трафик же пересылается с помощью обычного запроса от имени прокси.  

# Что умеет
- Обслуживание нескольких пользователей за раз
- Работа в любом современном браузере(т.к. поддерживает https протокол)
- Ведение логов(в файл и консоль одновременно)

# Стек технологий

- Python
- Socket, Threading, Logging

# Изменения
- Создана раздельная архитектура проекта
- Исправлены ошибки утечек сокета remote_socket в функциях http_funfc и https_funfc (ранее сокет не закрывался если была ошибка NameError при попытке создать remote_socket)
- Добавлены множество конструкций Try/Except/Finally для подробного ведения логов ошибок и дальнейшего их исправления. Теперь программа ведет себя более предсказуемо
- Хост, порт, конфигурации логгера и т.д. вынесены в отдельный файл config.py. Теперь можно настроить прокси под себя 

# Как запустить
```
git clone https://github.com/macos198766-arch/proxy
```
```
python3 proxy_server.py
```
Тестирование:
```
curl -v -x http://localhost:8888 https://www.google.com
```
https://www.google.com - адрес сайта который требуется посетить

Или настройте прокси сервер в параметрах операционной системы
